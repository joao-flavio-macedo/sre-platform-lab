# Objetivo do lab

Aprendizado e preenchimento de lacunas técnicas, com foco em operar
e explicar cada componente com autonomia.

## Módulos
- [ ] 0. Mapa do lab (WSL / GitHub Actions / OKE)
- [ ] 1. Containers e segurança de imagem
- [ ] 2. Terraform a fundo
- [ ] 3. Kubernetes: operação e troubleshooting
- [ ] 4. Helm + ArgoCD (GitOps)
- [ ] 5. GitHub Actions + registry (CD)
- [ ] 6. Observabilidade e SLOs no Kubernetes
- [ ] 7. Simulações de incidente e postmortem
- [ ] 8. Python para automação

## Critério de domínio por módulo
Objetivo, local de execução, mecanismo, evidência, risco
+ diagnóstico de uma falha provocada sem ajuda.
